# React E-Commerce – Completion Task

You have already built the product listing and Add to Cart feature.
Complete the project by implementing the following:

## Requirements
### 1️⃣ Display Cart & Favorites Count

- Show the number of items in Cart and Favorites inside the Navbar.

- The count must update automatically when items are added or removed.

### 2️⃣ Implement Favorites

- Add ❤️ Add to Favorites button in each Product Card.

- Save favorites in localStorage.

- Create a Favorites component to display saved items.

- Add a Remove button.

### 3️⃣ Prevent Duplicate Items

- Do not allow the same product to be added twice to Cart or Favorites.

- Check by product id before adding.

### 4️⃣ Add Quantity System (Cart)

If a product is added again:

- Increase its quantity instead of blocking it.

- Display quantity for each item in Cart.

- Add buttons to increase/decrease quantity.

### 5️⃣ Calculate Total Price

- Calculate the total price based on:

price × quantity


- Display the total price at the bottom of the Cart.

- Update it automatically when quantity changes.

### 6️⃣ Styling

- Apply clean and responsive styling.

Use:

Flexbox or Grid

Proper spacing

Buttons with hover effects

- Make Navbar visually clear and modern.

###  Bonus (Optional)

- Show an Empty Cart / Empty Favorites message.

- Add a clear Cart button.
